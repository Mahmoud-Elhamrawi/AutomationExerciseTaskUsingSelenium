<h1> 🧪 Selenium Automation Script - AutomationExercise.com </h1>

This project contains a Selenium automation script that performs end-to-end testing on [AutomationExercise.com](https://automationexercise.com/).

## ✅ Task Overview

The script automates the following flow:

1. Open the website: [https://automationexercise.com](https://automationexercise.com/)
2. Log in using valid user credentials.
3. Navigate to the **T-shirt** product page.
4. Add products priced **less than ₹1000** to the shopping cart.
5. Go to the **View Cart** page and capture a screenshot.

---

## 🛠️ Tech Stack

- **Language**:Java 
- **Framework**: Selenium WebDriver
- **Browser**: Chrome (via ChromeDriver)
- **Tools**: TestNg , Allure Report ,Maven
